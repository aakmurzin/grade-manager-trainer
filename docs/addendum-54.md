# Grade Business Trainer — Addendum 54

Удаление Rapid-режима. **4 квартала (48 недель)** — единственный формат тренажёра.

---

## Почему убрать, не чинить

Вся экономика (`addendum-08`→`53`) откалибрована под Definition of fair/winnable
(`addendum-15`): **Q1 минус при разумной игре — норма**, окупаемость Q2–Q4. Rapid (1 квартал)
структурно не может показать позитивный исход при разумной игре — разница между хорошим и
плохим игроком схлопывается до «чуть менее плохой Q1», что не измеряет управленческий навык.

Альтернативы (отдельная Rapid-калибровка; узкий диагностический этюд) требуют цикл,
сопоставимый с Design/Marketing, без продуктовой ценности. **Выбрано: убрать полностью.**

Rapid fair/winnable критерий из `addendum-15` / бэклога `addendum-53` — **отменён**, не
«нерешённый».

## Технические изменения

| Область | Изменение |

| UI | Экран выбора формата удалён; Company Select → сразу в сессию |

| HUD | Play/Pause + 1x/2x/3x всегда доступны |
| Batch harness | Только 4-quarter sessions; `PLAYTEST_FORMAT` удалён |
| DB/API | `sessions.format` пишет `'classical_4q'` (legacy Rapid rows сохраняются) |

Classical timing и вся закрытая калибровка — **без изменений**.
