## 2. Вердикт: рычаг исчерпан

s08 — **изолированный максимум**, не край кучи у нуля. Основная масса глубоко в минусе
(медиана −$7.7k, 8/12 ≤ −$5k). p90 = −$2.0k: даже «хороший» хвост не в зоне дожима бюджета.

Дополнительно: оставшаяся доля — **не один Q1-разрыв**. s10 имеет **самый мелкий Q1** (−$4480)
и cum −$9668, потому что Q2–Q4 все минус. Ещё +$500 старта это не лечит. Bankrupt 8.3% не
сдвинулся A21→A22 — бюджет бил по достижимости, не по краху и не по медиане.

**Не поднимаем до $20.5k.** Дальнейший бюджет расширял бы max, не медиану.
